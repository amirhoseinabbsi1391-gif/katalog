سؤالات متداول

آیا داده‌های من به سرور ارسال می‌شوند؟

خیر. تمام عملیات رمزنگاری در مرورگر شما و با استفاده از Web Crypto API انجام می‌شود. متن، کلید و فایل‌های شما هرگز از دستگاهتان خارج نمی‌شوند.

کدام الگوریتم برای رمزگذاری متن پیشنهاد می‌شود؟

AES-GCM با کلید ۲۵۶ بیتی. این الگوریتم هم رمزنگاری می‌کند و هم یکپارچگی داده را تضمین می‌کند (AEAD). برای فایل نیز AES-GCM پیشنهاد شده است.

آیا الگوریتم‌های کلاسیک (Caesar, Vigenere) امن هستند؟

خیر. این الگوریتم‌ها صرفاً جنبه آموزشی دارند و برای محافظت از اطلاعات واقعی مناسب نیستند. برای امنیت واقعی از AES-GCM یا RSA استفاده کنید.

چرا SHA-256 قابل رمزگشایی نیست؟

SHA-256 یک تابع هش یک‌طرفه است. طراحی آن به‌گونه‌ای است که بازگرداندن ورودی از خروجی عملاً غیرممکن باشد. برای تأیید یکپارچگی داده استفاده می‌شود.

آیا می‌توانم از این پروژه در محیط تولیدی استفاده کنم؟

ابزارهای رمزگذاری از استانداردهای معتبر استفاده می‌کنند اما این پروژه عمدتاً آموزشی است. برای محیط تولیدی، بررسی امنیتی مستقل و استفاده از KMS/HSM توصیه می‌شود.
